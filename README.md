# Number Drawing for Bingo 🎲

給 4 歲左右幼兒使用的 Bingo 抽數字網頁小遊戲。

▶️ 線上玩：https://christie-studio.github.io/bingo-number/

## 功能
- 🐢 小烏龜 3×3（數字 1～15）
- 🐰 小兔子 4×4（數字 1～25）
- 🦁 獅子 5×5（數字 1～40）
- 按一下抽一個數字，不會重複，並用中文語音念出
- 可產生 A4 Bingo 卡圖檔（一張 4 張不同的卡），下載後列印剪開

## 玩法
聽到數字後在自己的卡上找，橫、直或斜線連成一整條就喊 BINGO！

## 使用
單一 `index.html`，不需安裝，開啟網頁即可；也可放在 GitHub Pages。
